# Yuno 💌 — For My Love

A digital love letter for Shreemati — our memories, our songs, and a heart that is still counting.

Built with **React + TypeScript + Vite**, animated with **Framer Motion**, icons by **Lucide**.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Structure

- `src/data/loveSlides.ts` — every slide, message, nickname, Spotify link & the anniversary date
- `src/hooks/useCarousel.ts` — autoplay / navigation / pause-resume logic
- `src/components/` — carousel, hero, counter, memories, lightbox, letter & more
- `public/image/` — our photos (yuno1–yuno9)
